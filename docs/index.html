## features

Everything GitHub renders — natively, offline

A true macOS document app: multi-window, Open Recent, dark-mode aware. The rich rendering you expect, with none of the Electron weight.

⚡

Instant cold start

A single SwiftUI scene with bundled web assets — no remote fetch on launch. Opens in under 300 ms.

🔄

Live reload

Edit in any external editor; the preview updates in ≈130 ms and handles atomic saves cleanly.

🎨

GitHub-flavoured & themes

markdown-it with GFM tables and task lists — rendered in GitHub Light, GitHub Dark or a warm Sepia theme, per window.

🌈

Syntax highlighting

highlight.js with GitHub light & dark themes for fenced code blocks.

🧮

Math & diagrams

Inline and display math via KaTeX, plus Mermaid flowcharts, sequence and graph diagrams.

✏️

Built-in editor

Toggle Preview / Split / Source, with a syntax-highlighted source view, line-number gutter and native save.

🔍

Find, zoom & print

Native ⌘F search, ⌘± content zoom (per-window), and ⌘P print / Save as PDF.

👁️

Quick Look

Select a .md in Finder and hit Space — full rendering with code, math and diagrams, without opening the app.

🚀

One-click updates

Sparkle 2 + notarized DMGs + EdDSA signature — Check for Updates… downloads, swaps and relaunches.

// why it exists

Built for one job, done fast

macOS ships no real Markdown previewer — TextEdit shows raw text, and Electron apps take seconds to launch. MarkdownViewer delegates to native APIs wherever possible and drops into JavaScript only for what WKWebView renders for free. The result: a featherweight document app that feels instant.
